# 🌟 Diferenciais do Projeto

O projeto foi desenvolvido como um portal informativo sobre os campeões da Copa do Mundo FIFA.

Além da página principal, cada seleção campeã possui uma página exclusiva contendo:

- História da seleção
- Conquistas em Copas do Mundo
- Placar das finais vencidas
- Principais ídolos
- Curiosidades históricas

---

# 🌍 Navegação entre Páginas

O sistema permite navegar para páginas exclusivas das seleções campeãs:

- 🇧🇷 Brasil
- 🇦🇷 Argentina
- 🇩🇪 Alemanha
- 🇮🇹 Itália
- 🇫🇷 França
- 🇺🇾 Uruguai
- En Inglaterra
- 🇪🇸 Espanha

Cada página apresenta informações detalhadas sobre a trajetória da seleção nas Copas do Mundo FIFA.

# 📸 Demonstração

### Página Inicial
- Lista de campeões mundiais
- Ranking de títulos
- Maiores artilheiros
- Melhores jogadores
- Finais históricas

### Páginas das Seleções
- História completa da seleção
- Finais vencidas
- Craques históricos
- Curiosidades

### Navegação
- Links entre todas as páginas
- Retorno à página principal através do botão "Voltar"

# 🎯 Objetivo do Projeto

Criar uma aplicação web educativa e interativa que permita conhecer a história dos campeões da Copa do Mundo FIFA através de informações organizadas e navegação intuitiva.
