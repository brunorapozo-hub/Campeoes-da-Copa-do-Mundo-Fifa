# 🌎 Sobre o Projeto

O projeto **Campeões da Copa do Mundo FIFA** foi desenvolvido com o objetivo de apresentar informações históricas sobre a maior competição de futebol do planeta.

A aplicação permite que o usuário consulte seleções campeãs, títulos conquistados, anos das conquistas, maiores artilheiros, melhores jogadores e finais históricas das Copas do Mundo FIFA, através de uma interface moderna e interativa.

---

# 🚀 Funcionalidades

✅ Pesquisa dinâmica por seleção campeã

✅ Maiores artilheiros das Copas do Mundo
